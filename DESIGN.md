# DESIGN.md

## Brand
- Name: Malik Fajar
- Website: malikfajar.me
- Identity: cybersecurity learner, full stack developer, UI/UX designer

## Style Direction
- Brutalist
- Cyberpunk
- Futuristic
- Premium
- Minimal
- Clean
- Developer-focused
- Cybersecurity-focused

## Colors
- Background: near-black / black
- Primary accent: electric blue
- Secondary accent: yellow
- Text: white / off-white

## Visual Rules
- Strong typography
- High contrast
- Spacious layout
- Geometric shapes
- Minimal clutter
- Subtle glow only
- No excessive blur
- No generic glassmorphism overload

## Typography
- Big headline for hero
- Clear readable body text
- Compact labels for skills and metadata

## Layout Rules
- Mobile-first
- Responsive
- Clear section separation
- Strong hierarchy
- Easy scanning
- Premium spacing

## Motion Rules
- Smooth fade
- Gentle slide
- Small stagger
- No distracting looping animation
- Keep motion subtle and fast

## Media Rules
- Use optimized images
- Lazy load large assets
- Avoid performance issues
- Keep certificate gallery lightweight

## Section Order
1. Navbar
2. Hero
3. About
4. Skills
5. Projects
6. Certificates
7. Contact
8. Footer

## Hero Direction
- Desktop: landscape character on left, facing right
- Mobile: portrait character below, looking up
- Title: “Hey! I’m Malik!”
- Description:
  “A cybersecurity learner focused on pentesting and secure web development, while exploring 3D web experiences and modern UI.”

## Do Not
- Add backend code
- Add API routes
- Overdesign
- Use generic templates
- Use too many effects
- Break Vercel compatibility

## Quality Goal
The website should feel fast, modern, bold, and personal, with a strong cybersecurity/developer identity.
